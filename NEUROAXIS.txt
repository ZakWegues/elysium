1. O QUE É O NEUROAXIS
════════════════════════════════════════════════════════════════════════════════

NEUROAXIS é um assistente de voz pessoal para Windows que roda inteiramente
em segundo plano. Ativado por atalho de teclado global (Ctrl+Shift+J), ele
ouve um comando em português do Brasil, entende a intenção usando inteligência
artificial, executa a ação no computador e responde em voz alta.

Diferente de assistentes como Cortana ou Alexa, o NEUROAXIS:
- Roda 100% local no processo, sem dependência de serviços em nuvem além da
  API da Groq para transcrição e tomada de decisão
- Executa ações REAIS no PC: abre programas, controla volume, tira prints,
  lê clipboard, cria arquivos, fecha apps, informa status do sistema
- Suporta comandos compostos: "me diz as horas e quanto tem de espaço no HD"
- É totalmente configurável via interface gráfica
- Gera um instalador .exe funcional


════════════════════════════════════════════════════════════════════════════════
2. COMO FUNCIONA — FLUXO COMPLETO
════════════════════════════════════════════════════════════════════════════════

1. ATIVAÇÃO
   O usuário pressiona Ctrl+Shift+J (configurável) com qualquer janela em foco.

2. GRAVAÇÃO
   Uma janela oculta (recorder) captura áudio do microfone padrão via
   Web Audio API. A gravação para automaticamente após ~1,5s de silêncio
   detectado (configurável: 500ms–5000ms), com teto máximo de 2 minutos.
   O nível RMS do áudio é enviado em tempo real para animar o waveform
   visual na janela de voz.

3. TRANSCRIÇÃO (STT)
   O áudio WAV é enviado para a API da Groq usando o modelo Whisper
   (whisper-large-v3 ou whisper-large-v3-turbo). Retorna o texto falado
   em português.

4. DECISÃO (BRAIN)
   O texto transcrito é enviado para o modelo Llama (llama-3.3-70b-versatile
   ou llama-3.1-8b-instant) via Groq, com um system prompt cuidadosamente
   construído. A resposta é SEMPRE JSON estruturado no formato:

   {"actions": [<ação1>, <ação2>, ...]}

   Suporta múltiplas ações em um único comando. O histórico de conversa é
   mantido na memória (últimas 6 trocas por padrão), permitindo contexto
   entre pedidos. O histórico é limpo após 5 minutos de inatividade.

5. EXECUÇÃO
   Cada ação do array é executada sequencialmente pelo router. As ações
   são módulos TypeScript independentes que usam Node.js e PowerShell
   para interagir com o Windows.

6. RESPOSTA
   O resultado de cada ação é coletado e concatenado. A resposta combinada
   é sintetizada em voz pelo TTS (System.Speech do Windows, voz pt-BR) e
   falada ao usuário. Uma notificação nativa do Windows também aparece
   com o conteúdo da resposta.

3. INTERFACE E DESIGN
════════════════════════════════════════════════════════════════════════════════

O NEUROAXIS tem quatro janelas, todas com fundo escuro (#1a1a2e / #0d0d1a)
e tema visual dark com acentos em roxo/ciano (#7b5ea7, #4ecdc4):

────────────────────────────────────────────────────────────────────────────────
3.1 ÍCONE DA BANDEJA (TRAY)
────────────────────────────────────────────────────────────────────────────────
Vive exclusivamente na bandeja do sistema (system tray), sem aparecer na
barra de tarefas. Menu de contexto ao clicar com botão direito:

┌─────────────────────────────────────────┐
│  NEUROAXIS — Ocioso                     │  ← status atual
│  ─────────────────────────────────────  │
│  📋 abre o discord    (último comando)  │
│  ─────────────────────────────────────  │
│  ⚡ Frequentes  ▶  [top 5 comandos]    │  ← submenu clicável
│  🎮 Presets     ▶  [gaming, trabalho]  │  ← submenu clicável
│  ─────────────────────────────────────  │
│  🎤 Ativar voz...                       │
│  💬 Abrir chat...                       │
│  ⚙️  Configurações...                   │
│  ─────────────────────────────────────  │
│  🔄 Iniciar com Windows  ✓             │
│  ─────────────────────────────────────  │
│  ✕ Sair                                │
└─────────────────────────────────────────┘

- Status reflete o estado atual: Ocioso / Ouvindo / Processando / Falando
- "Frequentes": mostra os 5 comandos mais usados, cada um clicável
- "Presets": mostra todos os presets configurados, cada um clicável
- Último comando atualiza após cada execução bem-sucedida

────────────────────────────────────────────────────────────────────────────────
3.2 OVERLAY DE VOZ (voice-overlay.html)
────────────────────────────────────────────────────────────────────────────────
Janela 400×440px, não-redimensionável, sem menu:

- Texto de status central: "Ouvindo...", "Processando...", "Abrindo Discord...",
  "Consultando sistema...", "Falando..." — atualiza em tempo real antes de
  executar a ação
- Waveform animado: 5 barras verticais que pulsam proporcionalmente ao volume
  real do microfone (RMS). Cada barra tem fase levemente diferente para
  parecer orgânico. Ativo tanto na escuta quanto durante a fala.
- Transcrição aparece ao centro quando o texto é detectado
- Resposta final exibida com animação
- Estados visuais: listening (barras animam com áudio real), processing
  (barras com animação idle suave), speaking (barras animam)

────────────────────────────────────────────────────────────────────────────────
3.3 CHAT (chat.html)
────────────────────────────────────────────────────────────────────────────────
Janela 480×620px, redimensionável (mín. 400×500):

- Histórico de mensagens com bolhas estilo chat (usuário à direita, roxo;
  assistente à esquerda, mais escuro)
- Botão 📋 copiar em cada mensagem (aparece no hover, feedback "Copiado!" por
  1.5s)
- Timestamps visíveis permanentemente (não precisam de hover)
- Campo de input com contador de caracteres (aviso a partir de 400 chars,
  bloqueia a 500)
- Botão de microfone para ativar voz diretamente do chat
- Botão "Limpar histórico" com confirmação inline (2 cliques)
- Aba "Frequentes": mostra comandos mais usados; clicar executa o comando
- Aba "Presets": lista presets do arquivo de configuração
- Janela redimensionável para acomodar conversas longas

────────────────────────────────────────────────────────────────────────────────
3.4 CONFIGURAÇÕES (config.html)
────────────────────────────────────────────────────────────────────────────────
Janela 480×580px, não-redimensionável:

Seção: Conta
  - Campo API key da Groq (show/hide, placeholder com key atual mascarada)

Seção: Comportamento
  - Silêncio para parar (slider 500ms–5000ms, padrão 2500ms)
  - Gravação máxima (slider 10s–300s, padrão ilimitado)
  - Turnos de histórico no chat (slider 2–20, padrão 6)
  - Reset de histórico após inatividade (slider 1–60min, padrão 5min)
  - Atalho de teclado (campo de captura: pressione a combinação)
  - Iniciar com Windows (toggle)

Seção: Modelos de IA
  - Modelo STT: whisper-large-v3 / whisper-large-v3-turbo
  - Modelo Brain: llama-3.3-70b-versatile / llama-3.1-8b-instant

Rodapé:
  - Botão "Restaurar padrões" com confirmação (2 cliques)
  - Botão "Salvar e fechar"
  - Tecla Esc fecha a janela

4. FUNCIONALIDADES COMPLETAS
════════════════════════════════════════════════════════════════════════════════

────────────────────────────────────────────────────────────────────────────────
4.1 TOCAR MÚSICA (play_music)
────────────────────────────────────────────────────────────────────────────────
Abre o Spotify direto na busca do que foi pedido via protocolo spotify:search:
Se Spotify não estiver instalado, fallback para YouTube no navegador padrão.

Exemplos de comandos:
  "toca Bruno Mars"
  "coloca Bohemian Rhapsody"
  "bota funk dos anos 2000"
  "toca lofi para estudar"
  "coloca playlist de treino"
  "música do linkin park"

────────────────────────────────────────────────────────────────────────────────
4.2 ABRIR SITE / URL (open_url)
────────────────────────────────────────────────────────────────────────────────
Abre no navegador padrão. Aceita URL direta ou termo de busca (vai para YouTube
ou pesquisa web, dependendo do contexto).

Exemplos:
  "abre o YouTube"         → https://youtube.com
  "abre o Instagram"       → https://instagram.com
  "abre meu Gmail"         → https://mail.google.com
  "abre meu Drive"         → https://drive.google.com
  "abre o Google Meet"     → https://meet.google.com
  "abre meu Calendar"      → https://calendar.google.com
  "abre o Google Maps"     → https://maps.google.com
  "abre o TikTok"          → https://tiktok.com
  "abre o Twitter"         → https://twitter.com
  "pesquisa clima em SP"   → busca no YouTube/web

────────────────────────────────────────────────────────────────────────────────
4.3 ABRIR PROGRAMA (open_app)
────────────────────────────────────────────────────────────────────────────────
Abre programas instalados no Windows via mapeamento em apps.json. Se o nome
não estiver no mapa, tenta abrir pelo nome diretamente.

Programas mapeados (~80 entradas):
  Entretenimento:  Spotify, Discord, Steam, Epic Games, Roblox, Roblox Studio,
                   BlueStacks, Hydra, VLC, OBS Studio
  Produtividade:   VS Code, Notion, Slack, Teams, Zoom, Figma, Postman
  Microsoft:       Word, Excel, PowerPoint, Paint, Bloco de Notas, Calculadora,
                   Explorador de Arquivos, Edge, Task Manager, Configurações,
                   Câmera, Relógio, Snipping Tool, Windows Terminal, PowerShell
  Comunicação:     WhatsApp, Telegram, Chrome, Firefox
  Utilitários:     WinRAR, 7-Zip, Acrobat PDF Reader, MSI Afterburner,
                   Rainmeter, Lively Wallpaper, Vortex, Claude, NVIDIA App

Exemplos:
  "abre o Discord"
  "abre o Steam"
  "inicia o VS Code"
  "abre a calculadora"
  "abre o explorador de arquivos"

────────────────────────────────────────────────────────────────────────────────
4.4 FECHAR PROGRAMA (close_app)
────────────────────────────────────────────────────────────────────────────────
Fecha programas via PowerShell (Stop-Process). Usa o mesmo mapeamento do
open_app para encontrar o nome do processo.

Exemplos:
  "fecha o Chrome"
  "mata o Discord"
  "encerra o Spotify"
  "fecha o VS Code"

────────────────────────────────────────────────────────────────────────────────
4.5 CONTROLE DE VOLUME (volume_control)
────────────────────────────────────────────────────────────────────────────────
Controla o volume do sistema via PowerShell + Windows Audio APIs.
Suporta nível absoluto (0-100%), subir, descer, mutar e desmutar.

Exemplos:
  "aumenta o volume"       → sobe em ~10%
  "diminui o som"          → desce em ~10%
  "volume 50"              → vai para 50%
  "coloca no 30"           → vai para 30%
  "muta"                   → silencia
  "tira o mudo"            → desmuta

────────────────────────────────────────────────────────────────────────────────
4.6 ESCREVER TEXTO (write_text)
────────────────────────────────────────────────────────────────────────────────
O brain gera o texto completo e o NEUROAXIS copia para a área de transferência.
Usado para emails, mensagens, listas, etc.

Exemplos:
  "escreve um email pedindo férias"
  "monta uma mensagem de desculpas para o professor"
  "cria uma lista de tarefas para hoje"
  "redige um texto de 3 parágrafos sobre fotossíntese"

────────────────────────────────────────────────────────────────────────────────
4.7 CRIAR ARQUIVO (create_file)
────────────────────────────────────────────────────────────────────────────────
Cria arquivo .txt na Área de Trabalho com conteúdo gerado pelo brain.
Abre o arquivo automaticamente após criar.

Exemplos:
  "salva um arquivo com a receita de bolo de cenoura"
  "cria um documento com um cronograma de estudos"
  "cria uma lista de compras e salva em arquivo"

────────────────────────────────────────────────────────────────────────────────
4.8 PROCESSAR CLIPBOARD (clipboard_read)
────────────────────────────────────────────────────────────────────────────────
Lê o texto da área de transferência, processa com o brain conforme a instrução
e retorna o resultado via TTS (e copia de volta para clipboard quando cabível).

Exemplos:
  "traduz o que está copiado"
  "resume o que copiei"
  "corrige os erros do texto copiado"
  "o que tem na minha área de transferência?"

────────────────────────────────────────────────────────────────────────────────
4.9 SCREENSHOT (screenshot)
────────────────────────────────────────────────────────────────────────────────
Captura a tela inteira via PowerShell (System.Windows.Forms + System.Drawing),
salva como PNG na Área de Trabalho com timestamp e abre automaticamente.

Exemplos:
  "tira um print"
  "screenshot"
  "captura a tela"
  "faz um print da tela"

────────────────────────────────────────────────────────────────────────────────
4.10 INFORMAÇÕES DO SISTEMA (system_info)
────────────────────────────────────────────────────────────────────────────────
Consulta dados do sistema via PowerShell e retorna em linguagem natural pelo TTS.

Tipos de consulta:
  ram      → RAM usada e total (ex: "Usando 8 GB de 16 GB de RAM.")
  cpu      → Uso do processador (ex: "Uso de CPU: 23%.")
  battery  → Nível e estado da bateria (ex: "Bateria: 87%, carregando.")
  disk     → Espaço livre no disco C: (ex: "47 GB livres de 512 GB no disco C.")
  hora     → Hora atual (ex: "São 14h32.")
  data     → Data atual (ex: "Hoje é segunda-feira, 23 de junho de 2026.")

Exemplos:
  "que horas são"
  "que dia é hoje"
  "quanta RAM estou usando"
  "uso do processador"
  "quanto espaço tem no HD"
  "bateria do notebook"

────────────────────────────────────────────────────────────────────────────────
4.11 PRESETS (run_preset / list_presets / delete_preset)
────────────────────────────────────────────────────────────────────────────────
Presets são sequências de ações encadeadas. Definidas em presets.json,
executadas com "ativa o modo X" ou clicando no tray.

Presets incluídos por padrão:
  gaming:   Toca música "Go" no Spotify
  trabalho: Abre o VS Code + abre o Google Classroom no navegador

Ações suportadas dentro de um preset:
  play_music, open_url, open_app, close_app, volume_control, screenshot,
  write_text, create_file

Gerenciar presets por voz:
  "lista meus presets"        → lê todos os presets
  "quais presets tenho?"      → idem
  "apaga o preset gaming"     → remove do arquivo
  "remove o modo trabalho"    → remove do arquivo

────────────────────────────────────────────────────────────────────────────────
4.12 CHAT / CONVERSA (chat)
────────────────────────────────────────────────────────────────────────────────
Para qualquer pedido conversacional, o brain responde diretamente com até
2 frases claras e objetivas. Mantém histórico de contexto para perguntas
encadeadas.

Exemplos:
  "qual a capital da França?"
  "quanto é 247 vezes 8?"
  "o que é machine learning?"
  "me conta uma piada"
  "como vai você?"
  "oi"

────────────────────────────────────────────────────────────────────────────────
4.13 COMANDOS COMPOSTOS (múltiplas ações)
────────────────────────────────────────────────────────────────────────────────
O NEUROAXIS suporta múltiplas ações em um único comando de voz.
O brain retorna um array de ações executadas sequencialmente.

Exemplos:
  "me diz as horas e quanto tem de espaço no HD"
  → [system_info(hora), system_info(disk)]
  → "São 14h32. Você tem 47 GB livres."

  "que horas são e qual a bateria"
  → [system_info(hora), system_info(battery)]

  "abre o Discord e toca uma música animada"
  → [open_app(discord), play_music("música animada")]

  "fecha o Chrome e abre o VS Code"
  → [close_app(chrome), open_app(vs code)]

  "volume 40 e toca lofi"
  → [volume_control(40), play_music("lofi hip hop")]

  "tira um print e abre o Discord"
  → [screenshot, open_app(discord)]

  "quanta RAM estou usando e qual o uso do processador"
  → [system_info(ram), system_info(cpu)]

9. COMO USAR
════════════════════════════════════════════════════════════════════════════════

Desenvolvimento:
  npm run dev          build + abre o app em modo dev

Produção:
  npm run dist         build + gera instalador NSIS em release/

Após instalar:
  1. O app abre na bandeja automaticamente
  2. Na primeira execução: tela de configuração pede a API key da Groq
  3. Pressione Ctrl+Shift+J e fale um comando
  4. O NEUROAXIS responde em voz e executa a ação

Reiniciar o PC:
  O app inicia sozinho com o Windows (via auto-launch) sem nenhuma configuração.

10. SEGURANÇA E PRIVACIDADE
════════════════════════════════════════════════════════════════════════════════

- A API key da Groq é armazenada via electron-store (criptografia local do SO)
- A key NUNCA aparece em logs, código ou arquivos versionados
- O áudio é enviado para a Groq apenas quando o usuário ativa o assistente
  (não há escuta passiva em segundo plano)
- O histórico de conversa fica apenas em memória RAM (não persiste em disco)
- Processos do renderer rodam com contextIsolation: true e nodeIntegration: false
  (isolamento seguro entre renderer e main process)
- Cada BrowserWindow expõe apenas as APIs necessárias via contextBridge

11. RESOLUÇÃO DE PROBLEMAS
════════════════════════════════════════════════════════════════════════════════

PROBLEMA: Atalho não funciona com outro app em foco
SOLUÇÃO:  Alguns apps (jogos em fullscreen, apps administrativos) bloqueiam
          atalhos globais. Ative via ícone da bandeja → "Ativar voz...".

PROBLEMA: "Não entendi o áudio" toda vez
SOLUÇÃO:  Verifique microfone padrão em Configurações → Som.
          Fale mais próximo ao microfone. Reduza o ruído de fundo.

PROBLEMA: App não abre (nome não reconhecido)
SOLUÇÃO:  Adicione o app em src/config/apps.json:
          "nome que você fala": "comando_ou_exe"
          Depois rebuild: npm run build

PROBLEMA: TTS não fala (sem voz)
SOLUÇÃO:  Verifique em Configurações → Hora e idioma → Fala
          se há uma voz pt-BR instalada no Windows.

PROBLEMA: API key inválida / erro de rede
SOLUÇÃO:  Abra Configurações pelo tray, reinsira a key.
          Verifique conexão com internet.

PROBLEMA: Presets não funcionam após editar presets.json
SOLUÇÃO:  Execute npm run build para copiar presets.json para dist/.
